## 👨‍💻 My Story

I started with a simple question:

> **"How hard can working with data really be?"**

Then came joins, null values, schema mismatches, failed pipelines, dependency conflicts, and Docker containers that somehow work perfectly until you need to demo them.

So naturally, I decided to learn more.

I'm currently pursuing an **M.S. in Data Science at Virginia Commonwealth University**, where my interests have evolved from analyzing data to building the systems that make data and machine learning useful in the real world.

Today, my focus sits at the intersection of:

**Data Engineering → Machine Learning → AI Engineering**

I enjoy taking projects from **raw data to reliable, automated solutions** — designing pipelines, transforming and modeling data, training predictive models, orchestrating workflows, and building the infrastructure needed to make those systems repeatable.
